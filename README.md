# square

Square Home launcher modified to run as a landscape smart-TV / projector home screen: landscape lock, backup-based defaults, iOS-style status bar and a dynamic wallpaper that changes every minute.

- Build, install and architecture notes: [CLAUDE.md](CLAUDE.md)
- Release notes: [RELEASE.md](RELEASE.md)
- Dynamic wallpaper images: drop `.jpg/.png/.webp` files in [`wallpaper/`](wallpaper/) and rebuild (or `adb push` them to the device, see CLAUDE.md).
